推荐结论

2025-2026 生产级 Agent 主流架构 = 显式编排运行时 + 分层记忆 + MCP 工具层 + 内建观测/评测/护栏；推理循环按任务选 ReAct / Plan-Execute / Reflection；默认单 Agent，仅在角色边界清楚时引入多 Agent。

  • 长流程靠 state / checkpoint / durable execution，而非更长 prompt
  • MCP 正在快速收敛为跨厂商工具互操作标准（企业内部仍常用 OpenAPI）
  • 框架选型跟 模型与云生态锁定，不追 GitHub star

运行时架构

Anthropic 区分 Workflow（预定义路径）与 Agent（动态选工具）。2025 后重心：状态机编排、可恢复运行时、上下文工程。

单 Agent vs 多 Agent

OpenAI SDK 区分 Manager（子 Agent 当工具）与 Handoff（交控制权）。共识：多 Agent 仅在角色边界清楚时有 ROI。

MCP 与 A2A

MCP：JSON-RPC，标准化 tools/resources/prompts。OpenAI、Google、Pydantic AI、Strands 等已支持。A2A 补充 Agent 间互操作，不替代 MCP。
