# Phase 4 — 主动回忆测验(引擎)

> 最高杠杆的一步。对每张到期/新卡生成检索题,让用户**凭记忆先产出答案**才揭晓,跑预测-核对校准,再自评成 `{again,hard,good,easy}` 交给 Phase 5。
> **出任何测验前先 Read `assets/quiz-format.md`(Template Read Gate)。** 题干库见 `references/note-style.md`。
> 证据:检索练习 Roediger & Karpicke 2006(检索组一周遗忘 13% vs 重读 56%);首次回忆后重读无增益 Karpicke & Roediger 2008;元认知/流畅性错觉 Koriat & Bjork 2005。

## 铁律(一条规则同时落地两个最高证据机制)
**用户必须凭记忆先产出答案,才能揭晓。** 绝不把答案和线索并排;绝不在用户尝试前帮忙/给提示。

## 步骤(每张卡照 quiz-format.md 的序列走)
1. **出题**:开放**自由回忆 / 线索回忆 / 填空**。**默认禁**选择题/再认、是非、只给话题名考。每条笔记默认配 1 道 Understand 级自解释 + 1 道追问"为什么真?"。**随 reps 升深度**(Apply→Analyze→Evaluate),应用题用**全新场景**(绝不用原文例子)。
2. **只给线索**——绝不同时显示答案。
3. **预测(揭晓前)**:让用户预测自己会不会对(判断学习 JOL)。
4. **用户凭记忆作答** → 揭晓存储答案(must-have 要点 + 具名常见错误)→ 三档自评(Got It/Partial/Missed)→ 映射 `again/hard/good/easy`;用户可**否决**(交互边界)。
5. **回显校准差**:把"预测 vs 实际"长期累计("你在 N 张自以为稳的卡上栽了")。
6. 把每张卡的评分传给 **Phase 5**。

## 不许
- 不许在用户尝试前揭晓/提示。
- 不许用选择题糊弄(放流畅性错觉回来)。
- 不许让"我觉得会了/这个删了吧"驱动排程——信表现 + 日期。
