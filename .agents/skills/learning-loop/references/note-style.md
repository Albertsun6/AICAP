# note-style.md — 原子笔记规约 + 出题题干库

> 写笔记的逐字模板在 `assets/note-template.md`(那个是 Read-gate)。这里是**为什么这么写**的规约 + Phase 4 出题用的题干库。

## 原子/evergreen 笔记规约(Matuschak ~2019;Ahrens 2017 —— 手艺/中等证据,非 RCT)
- **概念导向、原子**:一条笔记 = 一个想法。能独立成立,不依赖被读的顺序。
- **标题像 API**:用**完整断言句**当标题(`间隔检索比集中重读更利于长期留存`),不是话题名(`间隔重复`)。好标题让笔记能被"调用"和链接。
- **自己的话**(生成效应):正文转述,不抄原文。抄=没经过你的脑子。
- **密集连结、no-orphan**:每条强制 `[[wikilink]]` 到 ≥1 条相关笔记。找相关笔记**本身就是自解释**。真没有 → 这是知识孤岛,补桥接笔记或质疑是否真懂。
- **引用纪律**(Ahrens 三笔记法的精神):文献→永久笔记转化时,`source:` 一路带到每条笔记的 `## Sources`,让接地结构化存活。

## 反模式(避开)
- **收藏家谬误**:存了 ≠ 学了。不产出理解、不连结、不进复习的笔记是负债。
- **誊抄非理解**:逐字摘抄是 Phase 2 要拦的。
- **孤岛笔记**:无 `[[link]]` 的笔记。
- **一源一笔记**:错。是**一想法一笔记**,跨源的同一想法合并。

## 出题题干库(Phase 4 用;Bloom 修订版作多样性脚手架,Anderson & Krathwohl 2001)
> 不是被验证的难度阶梯,只是**保证出题有变化、随 reps 升深度**的脚手架。

- **Understand(每条笔记默认)**:"用自己的话解释 ___" · "___ 的核心机制是什么?" · "把 ___ 讲给完全没背景的人"
- **Elaboration(每条事实默认)**:"为什么 ___ 是真的?" · "___ 和你已知的 ___ 怎么连?"
- **Apply(reps 升后)**:"如果 ___,会发生什么?" · "用 ___ 处理这个**全新**场景: ___"(绝不用原文例子)
- **Analyze**:"___ 和 [[Y]] 有何异同?" · "___ 的假设/边界条件是什么?"
- **Evaluate**:"什么时候 ___ 是**错**的选择?" · "___ 在什么情况下会失效?"

填空题:挖掉**承重的词/关系**,不是无关细节。永远开放产出,**不给选项**。
