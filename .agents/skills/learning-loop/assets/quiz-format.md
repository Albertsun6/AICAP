# quiz-format.md — 测验交互逐字格式(出任何测验前先 Read 这个)

> Phase 4 引擎。根植于检索练习(Roediger & Karpicke 2006, HIGH)+ 生成效应(Slamecka & Graf 1978)+ 元认知(Koriat & Bjork 2005, HIGH)。

## 唯一不可破的铁律
**用户必须凭记忆先产出答案,才能揭晓。** 绝不把答案和题并排;绝不在用户尝试前"帮忙"或给提示——否则把有效的费力检索降成无效的被动阅读。

## 每张卡的交互序列(逐字照走)
```
[卡 i/N · 笔记: <title> · reps=<r> lapses=<l>]

Q: <只给线索 cue,不含答案>

① 先预测:你觉得自己这道能答对吗?(对 / 不太确定 / 不会)     ← 判断学习(JOL),揭晓前必问
② 凭记忆作答(打出来):
   <等用户作答——不要替他答,不要给提示>
③ 揭晓参考答案:
   - 参考答案: <…>
   - must-have(满分要点): <…>
   - 常见错误: <名称> —— 为什么错: <…>
④ 自评(三档): Got It / Partial / Missed
   - 映射到 4 档: Missed→again · Partial/含糊→hard · Got It→good · 秒答且笃定→easy
   - 用户可**否决** agent 的自动评分(交互边界)
⑤ 校准回显: 你预测「<①>」,实际「<④>」。 <若预测对、实际错 → 标记"自以为会其实不会">
```
评分 `again/hard/good/easy` **确定性地**驱动 Phase 5 排程(闭环——不像 active-recall-practice 只出题不排程)。

## 出题规则
- **题型**:开放**自由回忆 / 线索回忆 / 填空**——用户**生成**答案。
- **默认禁止**:选择题/再认(放流畅性错觉回来,远弱于自由回忆)、是非题、只给"话题名"考(必须基于已摄入的笔记内容)。
- **应用题用全新场景**,绝不用原文自带的例子。
- **每条笔记至少自动配**:1 道 Understand 级自解释("用自己话解释 X")+ 1 道追问("为什么这是真的?")。
- **随 reps 升深度**(Bloom 修订版**作为出题多样性脚手架**,不是被验证的难度阶梯——Anderson & Krathwohl 2001):reps 攒多了爬到 Apply("若…会怎样?")、Analyze("和 [[Y]] 比")、Evaluate("什么时候 X 是错的选择?"),让复习不退化成死记。
- 题型跟笔记类型走:流程笔记→Apply;概念笔记→Analyze/对比。`和 [[Y]] 比` 里用 `[[wikilink]]` 顺带减少孤岛笔记。

## 校准(本 skill 存在的理由:压制流畅性错觉)
- 揭晓**前**问预测(JOL),揭晓后对比"预测 vs 实际",并**长期累计**这个差("你在 N 张自以为稳的卡上栽了")。
- **信检索表现 + 到期日期数学,不信学习者"我觉得会了 / 这个删了吧"**。自报信心和"drop it"请求**不**驱动排程。

## 参考答案 schema(随每张卡存)
参考答案 + must-have 要点 + 部分给分标准 + **具名常见错误**(及为何错)+ 针对性补救指向。
