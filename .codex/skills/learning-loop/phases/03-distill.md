# Phase 3 — 蒸馏成原子笔记(接地 + 核查)

> 目标:把已理解的材料拆成**原子、概念导向**的笔记,每条**绑到已抓取的来源**并做忠实性核查,用学习者自己的话写,带 `[[wikilinks]]` 和 SR frontmatter。
> **写任何笔记前先 Read `assets/note-template.md`(Template Read Gate)。** 规约见 `references/note-style.md`。
> 证据:原子笔记 Matuschak;引用纪律 Ahrens 2017;claim 拆解+核查 FActScore(Min 2023, ChatGPT 传记仅 58% 事实精度);忠实性门 Zhang 2024(检索降幻觉但不消除)。

## 步骤
1. **拆原子结论**:把理解拆成一个个**原子 claim**(一条一个事实/想法)。
2. **逐条接地(只对事实)**:每个**事实** claim 绑上**具体来源 + 引文片段**。**禁止闭书编事实**——绑不到已抓取来源的事实,要么丢弃,要么显式标 `unverified / 我的推断`。
   - 只有**事实**需要接地;例子、观点、学习者自己的推理**不**逐条接地(避免过度拆解)。
3. **忠实性核查**:回去**重读被引段落**,自问"这句是**字面支持**还是我外推了?";外推的**降级/标记**。可选 CoVe 自检(Dhuliawala 2023)——但它和模型共享盲区,**权威核查仍是回去重读原文**(呼应你的异构验证原则:高风险事实可另上一个跨模型 lens)。
4. **写笔记**(照模板):
   - **一想法一笔记**(绝不一源一笔记);文件名 = 完整断言式概念标题。
   - 正文**自己的话**;
   - 强制 `## Links` ≥1 条 `[[wikilink]]`(**no-orphan**);
   - `## Sources` 带作者/年份或 URL;
   - YAML frontmatter SR 区块(新卡初值见模板/scheduler.md);
   - 单一来源的承重结论标 `confidence: low`。

## 不许
- 不许写无来源的"事实"。
- 不许产出孤岛笔记(无 `[[link]]`)。
- 不许把外推当成被证实的事实。
