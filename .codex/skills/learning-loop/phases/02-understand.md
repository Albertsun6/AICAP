# Phase 2 — 理解门(写任何笔记之前)

> 目标:**先理解,再蒸馏**,让笔记是"可学习的产物"而非誊抄。**概念没被用大白话讲回来、缺口没补上,不许写任何原子笔记。** 证据:自解释/费曼(Bisra 2018, g=0.55)、生成效应(Slamecka & Graf 1978)、追问(Dunlosky 2013)。闭书生成是关键细节(Fiorella & Mayer 2016)。

## 步骤
1. **闭书自解释**:写笔记前,**不看原文**,用大白话把每个概念解释一遍——**像讲给一个零基础的人**。可以是 agent 讲、也可以 agent 引导用户讲。
2. **找洞**:agent 把术语、含糊、一带而过的地方标成**缺口标记**,在缺口处问**针对性**问题:"这为什么成立?" / "它和你已经懂的 ___ 怎么连起来?"
   - 边界:追问只用于**有先验知识的因果/关系型**内容——**别**对每个事实都机械问"为什么"。
3. **沉淀**:用户/agent 的自解释成为笔记的 `## My Understanding`(费曼)段;**找相关已有笔记的过程本身**驱动 `[[wikilink]]` 的产生(这也是自解释)。
4. **拒绝近似逐字复制**:发现是在抄原文而非转述 → 打回,重新闭书讲。

## 通过标准(满足才进 Phase 3)
- 能不看原文把核心讲清;
- 缺口处的"为什么/怎么连"有了答案;
- 已经能指出它和哪些已有概念相关(为连结做好准备)。

## 不许
- 不许跳过理解直接蒸馏。
- 不许把原文整段塞进 `## My Understanding`。
